REST API Specifications

Every response returns a structured JSON payload with uniform keys: success, message, data, and optional pagination or error.

👨‍🎓 Students API (/api/students)

GET /api/students - List students with search, filters (status, gender), sorting (sortBy, sortOrder), and pagination (page, limit).
GET /api/students/:id - Retrieve single student with their enrolled courses & academic history.
POST /api/students - Create new student. Validates unique student_id and email.
PUT /api/students/:id - Full update of student record.
PATCH /api/students/:id - Partial update of student record.
DELETE /api/students/:id - Delete student (cascades related enrollments).

📚 Courses API (/api/courses)

GET /api/courses - List courses with search, filters (department, credits), sorting, and active enrollment count.
GET /api/courses/:id - Retrieve course by ID with roster of enrolled students and seat availability.
POST /api/courses - Create course. Enforces unique course_code, credit bounds (1-6).
PATCH /api/courses/:id - Update course details.
DELETE /api/courses/:id - Delete course (protected if active enrollments exist).

📝 Enrollments API (/api/enrollments)

GET /api/enrollments - List enrollments with filters (student_id, course_id, semester, status, grade).
GET /api/enrollments/:id - Get enrollment record by ID.
POST /api/enrollments - Enroll student. Enforces active student status, capacity limits, and duplicate enrollment constraints.
PATCH /api/enrollments/:id - Update grade or status (e.g. 'Completed', 'Dropped').
DELETE /api/enrollments/:id - Remove enrollment.
